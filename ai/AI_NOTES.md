# AI Notes - How i used AI

I used different AI tools and methods throughout the project. First, while developing my understanding of the project, 
course materials and data, I used ChatGPT to help me close my knowledge gaps. It also helped me plan how to approach 
the project and connect the data and features that I used in Project A. CHATGPT functioned as my thinking partner, it 
helped me clarify my thought process and create precise prompts that translated exactly what I was thinking to the AI 
agent.

For example, I wanted my project to compare VADER and finVADER to identify which approach worked better when incorporated
into the portfolio, as I initially thought that finVADER would improve the outcome. At the beginning, the agent simply 
generated the “Equity Minimum Variance — Sentiment Fusion” analysis. However, after reviewing the overall storyline, I 
felt that the section was disconnected. I returned to CHATGPT to discuss whether anything was missing.

After several back-and-forth discussions, I realised that I had not explained how the portfolio weights changed after 
incorporating sentiment scores. As a result, jumping directly to the sentiment-fusion performance created confusion. 
CHATGPT then helped me create a prompt for the “Average Weight Changes After Sentiment Fusion” figure, which connected 
the overall story by showing the link between sentiment, portfolio weights and investment performance.

Since I was unfamiliar with some of the economic concepts, I also asked CHATGPT to review what I had written and help me 
correct and elaborate on the concepts and their economic implications. This allowed me to learn from the explanations 
while completing the project.

I also used CLAUDE to double-check the logic of my report and the figures included, particularly whether the overall 
discussion was connected and remained within the project scope. CLAUDE functioned as a project manager in this project
by helping me review broader logical connections and decisions throughout the project.

Finally, I used OpenCode in PyCharm to generate and refine the code throughout the project because it could directly 
access the provided code, project brief and relevant project context. It also helped me record the working process in 
the prompt log, including the actions it performed, the issues we encountered and how we resolved them. I checked 
everything OpenCode produced to ensure that it aligned with my intentions before asking it to add an entry to the prompt 
log. OpenCode functioned as the engineer in this project by supporting the technical implementation. I reviewed its 
outputs, tested the generated code and used the results to guide further decisions and revisions.
